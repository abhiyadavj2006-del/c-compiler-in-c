cc0 — a minimal C compiler, written in C

A real compiler, not a simulation. It lexes, parses, and generates x86-64 assembly for a small subset of C, then assembles and links it with gcc into a runnable program.

Try it live — right here in your browser

No server, no install, no account. This page runs a pure-JavaScript interpreter (cc0.js, same file, no CDN) for the exact C subset the real compiler supports — functions and recursion, for, if/else if/else, break/continue, globals, char, void, bitwise/shift operators — plus printf with %d/%c/%s (a web-only extra; the real compiler has no strings). Pick an example, edit it, and hit Run. A step limit (1,000,000 steps) plus a 3 second time limit stop infinite loops from ever hanging the page.

How it works


source .c  →  lexer  →  recursive-descent parser (AST)
           →  x86-64 code generator (AT&T assembly)
           →  gcc (assembler + linker)  →  executable


Variables live in 8-byte slots on the stack (-8(%rbp),
-16(%rbp), …). Expressions are evaluated onto %rax
with a push/pop stack machine. print(x) is a builtin that calls
printf("%d\n").



What it supports


    
  
  • User-defined functions with parameters, calls, and recursion —
      int add(int a, int b) { return a + b; }, plus
      void functions (up to 6 arguments, System V ABI)
    • 
  
  • int main() { … } (required entry point)
    • 
  
  • Global variables: int g = 5; and int h;
    • 
  
  • int x; / int x = <expr>; and
      x = <expr>;, x += …;, x++;,
      ++x;
    • 
  
  • char c = 'A'; and character literals ('a',
      '\n', …)
    • 
  
  • return <expr>; (becomes the program's exit code)
    • 
  
  • print(<expr>); builtin
    • 
  
  • if / else if / else, while,
      for (init; cond; incr), break /
      continue
    • 
  
  • Block scoping and shadowing: { int x = 2; }
    • 
  
  • Expressions: + - * / %, unary -,
      !, ~, << >>,
      & ^ |, == != < <= > >=,
      && ||, parentheses,
      // and /* … */ comments
    •

    return 42;
}


Output: exit code 42 (nothing printed — the value is the exit code).



Example 2 — arithmetic and precedence


int main() {
    return 2 + 3 * 4;   // * binds tighter than +
}


Output: exit code 14



Example 3 — variables


int main() {
    int a = 10;
    int b = 20;
    int c = a + b * 2;
    return c;
}


Output: exit code 50


cc0 turns this into real assembly (./cc0 --asm tests/test3_variables.c -o out.s):


    .text
    .globl main
main:
    push %rbp
    mov %rsp, %rbp
    sub $32, %rsp
    mov $10, %rax
    mov %rax, -8(%rbp)
    mov $20, %rax
    mov %rax, -16(%rbp)
    mov -8(%rbp), %rax
    push %rax
    mov -16(%rbp), %rax
    push %rax
    mov $2, %rax
    mov %rax, %rcx
    pop %rax
    imul %rcx, %rax
    mov %rax, %rcx
    pop %rax
    add %rcx, %rax
    mov %rax, -24(%rbp)
    mov -24(%rbp), %rax
    jmp .L0
    mov $0, %rax
.L0:
    leave
    ret



Example 4 — print and a loop


int main() {
    int i = 1;
    int total = 0;
    while (i <= 5) {
        total = total + i;
        i = i + 1;
    }
    print(total);
    return 0;
}

15

Example 6 — functions and recursion (new in the advanced update)


int fact(int n) {
    if (n <= 1) {
        return 1;
    }
    return n * fact(n - 1);
}

int main() {
    print(fact(5));
    return 0;
}


Output:


120


Arguments are passed in registers (%rdi, %rsi, …, System V
ABI), each function gets its own stack frame, and the stack is kept
16-byte aligned at every call — so recursion just works.

How to run it


The playground above is a JavaScript interpreter for the same language.
The compiler itself runs on Linux with gcc installed.
No server, no account, no environment variables.


git clone <your-repo-url>
cd c-compiler-in-c      # this folder is a standalone repo (suggested name)
make                    # builds ./cc0 from src/main.c
./cc0 tests/test3_variables.c -o prog
./prog; echo $?         # → 50
./run_tests.sh          # runs all 9 tests (9 passed, 0 failed)


See README.md for the full list of what was
tested, the limitations, and the next steps.



Limitations


    
  
  • Only int and char (char is stored like
      int) — no pointers, arrays, structs, strings, or floats.
    • 
  
  • At most 6 function parameters / arguments.
    • 
  
  • No preprocessor (#include / #define).
    • 
  
  • Only 64-bit x86-64 Linux; division by zero crashes, as in C.
    • 
  
  • Exit codes are 8-bit, so return 300; shows up as 44.
    • 
  
  • The in-browser interpreter adds printf with
      %d/%c/%s and string literals,
      which the real compiler does not support — and it reports division
      by zero as an error instead of crashing.
