cc0 — a minimal C compiler, written in C

A real compiler, not a simulation. It lexes, parses, and generates x86-64 assembly for a small subset of C, then assembles and links it with gcc into a runnable program.

How it works

source .c  →  lexer  →  recursive-descent parser (AST)
           →  x86-64 code generator (AT&T assembly)
           →  gcc (assembler + linker)  →  executable

Variables live in 8-byte slots on the stack (-8(%rbp), -16(%rbp), …). Expressions are evaluated onto %rax with a push/pop stack machine. print(x) is a builtin that calls printf("%d\n").

What it supports

  • int main() { … } — the only function
  • int x; / int x = <expr>; and x = <expr>;
  • return <expr>; (becomes the program's exit code)
  • print(<expr>); builtin
  • if / else and while
  • Expressions: + - * / %, unary - and !, == != < <= > >=, && ||, parentheses, // and /* … */ comments

Example 1 — return a constant

int main() {
    return 42;
}

Output: exit code 42 (nothing printed — the value is the exit code).

Example 2 — arithmetic and precedence

int main() {
    return 2 + 3 * 4;   // * binds tighter than +
}

Output: exit code 14

Example 3 — variables

int main() {
    int a = 10;
    int b = 20;
    int c = a + b * 2;
    return c;
}

Output: exit code 50

cc0 turns this into real assembly (./cc0 --asm tests/test3_variables.c -o out.s):

    .text
    .globl main
main:
    push %rbp
    mov %rsp, %rbp
    sub $32, %rsp
    mov $10, %rax
    mov %rax, -8(%rbp)
    mov $20, %rax
    mov %rax, -16(%rbp)
    mov -8(%rbp), %rax
    push %rax
    mov -16(%rbp), %rax
    push %rax
    mov $2, %rax
    mov %rax, %rcx
    pop %rax
    imul %rcx, %rax
    mov %rax, %rcx
    pop %rax
    add %rcx, %rax
    mov %rax, -24(%rbp)
    mov -24(%rbp), %rax
    jmp .Lret
    mov $0, %rax
.Lret:
    leave
    ret

Example 4 — print and a loop

int main() {
    int i = 1;
    int total = 0;
    while (i <= 5) {
        total = total + i;
        i = i + 1;
    }
    print(total);
    return 0;
}

Output:

15

Example 5 — division, modulo, comparison, if/else

int main() {
    print(17 / 5);
    print(17 % 5);
    print(3 < 5);
    if (10 > 5) { print(1); } else { print(0); }
    return 3 < 5;
}

Output:

3
2
1
1

Exit code: 1

How to run it

This page is only a demo — the compiler itself runs on Linux with gcc installed. No server, no account, no environment variables.

git clone <your-repo-url>
cd c-compiler-in-c      # this folder is a standalone repo (suggested name)
make                    # builds ./cc0 from src/main.c
./cc0 tests/test3_variables.c -o prog
./prog; echo $?         # → 50
./run_tests.sh          # runs all 5 tests (5 passed, 0 failed)

See README.md for the full list of what was tested, the limitations, and the next steps.

Limitations

  • Only int main() — no other functions, no function calls except the print() builtin.
  • Only int — no char, pointers, arrays, structs, strings, or floats.
  • No preprocessor (#include / #define).
  • Only 64-bit x86-64 Linux; division by zero crashes, as in C.
  • Exit codes are 8-bit, so return 300; shows up as 44.
